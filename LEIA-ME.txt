SIG - Sistema Integrado de Gestão · Almadina-BA · Versão 1.0
Publicação no GitHub Pages com banco de dados Firebase

ARQUIVOS DESTA PASTA
- index.html ...... o sistema completo
- SIG.ico ......... ícone (aparece na aba do navegador)
- firestore.rules . regras de segurança do banco de dados
- LEIA-ME.txt ..... este guia

=====================================================================
PARTE 1 - CRIAR O BANCO DE DADOS NO FIREBASE (gratuito, ~10 minutos)
=====================================================================
1. Acesse https://console.firebase.google.com e entre com uma conta Google
   (de preferência uma conta da Prefeitura).
2. Clique em "Criar um projeto" (ou "Adicionar projeto"), dê o nome
   "sig-almadina", desative o Google Analytics (não é necessário) e conclua.

3. LOGIN (Authentication)
   - No menu à esquerda: Criação > Authentication > Vamos começar.
   - Aba "Método de login" > "E-mail/senha" > ative a primeira opção > Salvar.

4. BANCO DE DADOS (Firestore)
   - Menu: Criação > Firestore Database > Criar banco de dados.
   - Local: southamerica-east1 (São Paulo).
   - Modo: "Iniciar no modo de produção" > Criar.
   - Abra a aba "Regras", apague tudo, cole o conteúdo do arquivo
     firestore.rules desta pasta e clique em "Publicar".

5. CHAVES DO PROJETO
   - Clique na engrenagem (ao lado de "Visão geral do projeto") >
     Configurações do projeto.
   - Em "Seus apps", clique no ícone </> (Web), dê o apelido "SIG" e
     clique em "Registrar app" (não marque Hosting).
   - Aparece um trecho "const firebaseConfig = { apiKey: ..., ... }".
     Copie os valores.

6. COLAR AS CHAVES NO SISTEMA
   - Abra o index.html no Bloco de Notas.
   - Logo no começo do <script> há o bloco "CONFIGURAÇÃO DO FIREBASE".
     Preencha entre as aspas: apiKey, authDomain, projectId,
     storageBucket, messagingSenderId e appId. Salve o arquivo.

=====================================================================
PARTE 2 - PUBLICAR NO GITHUB PAGES
=====================================================================
1. Entre em https://github.com com a sua conta.
2. Clique em "+" > New repository. Nome: sig. Marque "Public".
   Clique em "Create repository".
3. Clique em "uploading an existing file" (ou Add file > Upload files),
   arraste index.html e SIG.ico e clique em "Commit changes".
   (Não envie o firestore.rules nem este LEIA-ME; não precisam ir para o site.)
4. Vá em Settings > Pages. Em "Branch", escolha "main" e "/ (root)" e
   clique em Save.
5. Em 1 ou 2 minutos o endereço fica pronto:
   https://SEU-USUARIO.github.io/sig/

6. Volte ao Firebase: Authentication > Configurações > Domínios
   autorizados > Adicionar domínio > digite SEU-USUARIO.github.io

=====================================================================
PARTE 3 - PRIMEIRO ACESSO
=====================================================================
1. Abra o endereço do site. O status deve mostrar "Conectado · painel público".
2. Clique em "Modo administrativo". Como é a primeira vez, o sistema pede
   para criar o ADMINISTRADOR (nome, usuário e senha). Guarde bem a senha.
3. Na aba "Usuários", crie os logins dos agentes (Cadastrador ou Consulta).

=====================================================================
COMO FUNCIONA A SEGURANÇA
=====================================================================
- Sem login, qualquer pessoa vê apenas o Painel e os Bairros (totais e
  percentuais), sem nomes nem documentos. Ideal para a Smart TV.
- Os cadastros só podem ser lidos por usuários ativos. Cadastrar e editar:
  Administrador e Cadastrador. Excluir, exportar, bairros, usuários e
  auditoria: só Administrador. Essas regras são aplicadas pelo próprio
  Firebase, não apenas pela tela.
- A auditoria não pode ser alterada nem apagada por ninguém.
- Senha esquecida: o administrador remove o usuário e cria um login novo
  (com outro nome de usuário). A própria pessoa pode trocar a senha pelo
  botão com o nome dela, no topo.

=====================================================================
SE ALGO NÃO FUNCIONAR
=====================================================================
- "Banco de dados não configurado": as chaves não foram coladas no index.html.
- "Não foi possível ler o banco de dados": as regras do Firestore não foram
  publicadas (Parte 1, item 4).
- "Ative o login por e-mail e senha": falta o item 3 da Parte 1.
- Mudou o index.html no GitHub e não atualizou? Aguarde 2 minutos e
  recarregue com Ctrl+F5.

Plano gratuito do Firebase (Spark): 50 mil leituras e 20 mil gravações por
dia, suficiente para o município.

Modo Smart TV: abra o endereço do site com #tv no final, por exemplo
https://SEU-USUARIO.github.io/sig/#tv
